# 守钱记 Android 3.0

这是“守钱记”的原生 Android 安装版工程，不依赖 PWA，不需要浏览器。

## 最终目标
构建后会得到：

`守钱记_Android_3.0.apk`

把 APK 通过电脑微信发送到 OPPO 手机，下载后点击 APK，即可按 ColorOS 提示安装。

## 版本特性
- 原生 Android WebView 容器，全屏独立运行
- 软件本体完全离线
- 收入 / 支出快速记账
- 最近常用快捷复记
- 每日预算与“今日守住”
- 月度存钱目标
- 独立存钱目标
- 冲动消费冷静区
- 月度分析与最近 7 天趋势
- 数据保存在应用本机空间
- JSON 备份可导出到手机文件
- JSON 备份可从手机文件导入
- Android 返回键：先关闭弹窗 / 返回首页，再退出应用

## OPPO 安装说明
1. 将 APK 从电脑微信发送到手机。
2. 在手机微信中下载 APK。
3. 点击 APK。
4. ColorOS 若提示“禁止安装未知来源应用”，按页面提示为微信开启本次“安装外部来源应用”权限。
5. 返回安装页并安装。
6. 安装完成后，桌面会出现“守钱记”。

注意：首次自行打包的 APK 不经过应用商店签名，ColorOS 可能显示风险提醒，这是侧载 APK 的正常系统提示。请仅安装你自己生成、来源明确的版本。

## 数据提醒
卸载 App 会清除应用内数据。重要账目请定期使用“我的 → 导出备份”。
